# Mango

![.NET](https://img.shields.io/badge/-.NET-blue?logo=.net&logoColor=white)

## 📝 Description

Mango is a high-performance, scalable application built on the powerful .NET framework. Designed with modern architecture in mind, Mango provides a seamless user experience while maintaining the enterprise-grade stability and security that developers expect from the .NET ecosystem. Whether it is handling complex data processing or delivering a responsive interface, Mango is engineered to be as refreshing and efficient as its namesake.

## 🛠️ Development Setup

### .NET Setup
1. Install [.NET SDK](https://dotnet.microsoft.com/)
2. Restore dependencies: `dotnet restore`
3. Build the project: `dotnet build`
4. Run the project: `dotnet run`
